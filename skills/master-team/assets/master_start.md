# Master 启动提示

先区分用户是首次上手、恢复教学、执行业务还是维护技能。首次上手按技能references/onboarding.md逐步引导；已知信息不重问，已有团队和明确任务不强制重学。只审阅/改技能不启动教学。教学入口见 [first_use](first_use.md)。

使用 master-team 配置或恢复本项目协作。先核当前平台、真实工具及已有授权，读取项目入口、公共规则、本角色、当前状态和登记表相关项；选择persistent、parent_scoped或manual模式。复用已有成员，按实际任务配置角色，不自动创建六人团队。

若只改技能/配置，只处理文件。若接任，执行team_protocol的交接步骤；未确认所有者时保持只读，不重派在途任务。缺少通信或转移能力时交接文件并说明限制，不假称接管完成。

Codex 可用 `$master-team`，Claude Code 可用 `/master-team`，DSH用当前界面实际支持的技能调用方式或自然语言指定名称；名称不是创建/发送的授权。
